PipeLine Social

A personal, single-operator dashboard used to schedule and publish content to the owner’s own social media accounts through official platform APIs. It is not offered as a service to third parties and has no public sign-up.

Connected platforms

The panel publishes the owner’s own videos to YouTube, TikTok and Instagram. On YouTube it uses YouTube API Services to upload the owner’s own videos to the owner’s own channel and to read that channel’s name so the panel can show which channel is connected. It does not display, embed, aggregate or analyse any other channel’s content.
